# jisuan

中文卡西欧风科学计算器网页。

## 已实现

- 标准四则运算、括号、百分号、乘方、开方、阶乘、余数
- 角度模式切换：度、弧度、百分度
- 三角函数、反三角函数、双曲函数、指数、对数、常量 π / e、随机数、组合排列
- 矩阵：2×2 / 3×3 的加减乘、转置、行列式、逆矩阵
- 统计：一元样本录入、均值、方差、标准差、极值
- 复数：四则运算、共轭、模长、辐角
- 进制转换：二、八、十、十六进制
- 中文界面、按钮悬停说明、单屏式计算器布局

## 还未实现

- 分数化简、带分数 / 假分数互转
- 度分秒（60 进制）计算与极坐标 / 直角坐标互转
- 素因数分解、ENG、有效数字与小数位自定义
- 线性方程组、高次方程、不等式、SOLVE、比例式
- 4 阶以上矩阵、向量、统计回归、概率分布
- 数值微分、数值积分、Σ 求和
- 逻辑运算、函数表格、电子表格、科学常数、单位换算

## 使用方式

直接打开 `index.html` 即可使用。页面默认是单屏式计算器布局，显示屏会固定在顶部，不需要来回滚动页面。
