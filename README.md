页面顶部固定导航栏提供 **四个工具栏目**，点击即切换，当前选择记忆在浏览器中，也支持 URL 深链接直达：

## 一、科学计算器

卡西欧 fx-991 风格的单屏计算器，保留原有所有功能，含以下 11 种模式（通过页面内的二级标签切换）：

### 1.1 标准模式
四则运算、括号、乘方、开方、阶乘、百分比、常量 π / e、三角/反三角/双曲函数、对数指数、组合排列（nCr/nPr）、随机数、Ans 与内存（M+ / M- / MR / MC）。

### 1.2 方程模式
- 2~4 元线性方程组（高斯消元）
- 2~4 次多项式求实根（二分法）
- SOLVE（牛顿法求方程 f(x)=0 的根）
- 不等式求根
- 比例式 a/b = c/d 求解

### 1.3 矩阵模式
2×2 / 3×3 / 4×4 矩阵的加法、减法、乘法、转置、行列式、逆矩阵。

### 1.4 向量模式
三维向量 v1、v2 的加法、减法、点积、叉积、模长、夹角。

### 1.5 统计模式
逐条录入样本数据，实时计算样本数、总和、均值、方差、标准差、最小值、最大值。

### 1.6 微积分模式
- 一阶 / 二阶数值导数
- 辛普森定积分数值计算
- Σ 求和（上下限 ±100000）

### 1.7 复数模式
复数四则运算、共轭、模长、辐角计算。

### 1.8 进制模式
二进制 / 八进制 / 十进制 / 十六进制互转，支持小数与负数。

### 1.9 逻辑模式
AND、OR、XOR、NOT、XNOR 位运算，可按二/八/十/十六进制显示。

### 1.10 表格模式
输入 f(x)、g(x) 与起始值、结束值、步长，生成函数值表。

### 1.11 工具模式
分数化简与带分数互转、度分秒（DMS）、极坐标/直角坐标互转、素因数分解（≤10¹²）、ENG 记数、随机数、科学常数、单位换算（长度/质量/时间/速度/压强/能量/温度）。

## 二、布尔化简

将布尔化简器项目的核心功能完整移植为独立工具栏目，基于 [Quine-McCluskey 算法](https://en.wikipedia.org/wiki/Quine%E2%80%93McCluskey_algorithm)，在浏览器端纯前端运行。

### 2.1 核心流程

1. **配置变量**：输入变量名（逗号分隔，最多 10 个），设置输出个数（最多 10 个）
2. **预设快捷**：一键选择 2~5 输入组合，自动填充变量
3. **生成真值表**：自动生成所有输入组合，每行可手动设置输出为 `0` / `1` / `x`（无关项）
4. **一键化简**：点击「生成最简表达式」，算法自动找出最少字面量的覆盖集
5. **结果展示**：给出「最简表达式」和「标准形式」，自动识别并标注异或 (⊕) / 同或 (⊙)
6. **一键复制**：每个结果旁边有复制按钮

### 2.2 符号约定

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| `!` | NOT（取反） | `!A` |
| `&` | AND（与） | `A & B` |
| `#` | OR（或）—— 最简表达式中使用 | `A # B` |
| `+` | OR（或）—— 标准形式中使用 | `A + B` |
| `⊕` | XOR（异或） | `A ⊕ B` |
| `⊙` | XNOR（同或） | `A ⊙ B` |

### 2.3 支持特性

- 无关项（Don't-care）：输出设为 `x` 可优化化简结果
- 多输出：支持多个输出列同时化简
- 10 变量 10 输出：最多 1024 行真值表
- 正变量项优先排序：与原 Python 版本输出一致

## 三、实验记录

面向物理 / 化学等实验课的现场数据记录工具，支持手机端使用。

### 3.1 实验项目管理

- 创建多个实验项目，自定义数据列（例如：测量次数、电压 U/V、电流 I/A）
- 项目切换、重命名、删除（二次确认防误操作）
- 数据持久化保存在浏览器 localStorage 中

### 3.2 数据录入

- 手机端当场输入数据，每行有逐字段输入框
- 添加后自动生成可编辑的记录表（单元格可直接修改）
- 支持逐行删除，清空全部记录

### 3.3 自动图表

- 自动检测数值列，生成折线图 / 散点图 / 柱状图
- 可自由选择横轴（记录序号或任意列）和纵轴（任意列）
- 图表随数据变化实时更新

### 3.4 实验现象拍照

- 手机端点击「拍照」直接调起系统相机
- 支持从相册选择已有照片
- 照片自动压缩（JPEG 品质 0.6，最大 900px）保存在浏览器中
- 每个项目最多 12 张照片，超出自动移除最早的

### 3.5 导出 CSV

- 一键导出当前项目的完整数据（含表头）
- CSV 带 BOM 头，Excel 直接打开不乱码
- 文件名自动使用项目名称（非法字符自动替换为 `_`）

### 3.6 示例数据

首次打开自动创建一个「伏安法测电阻」示例项目，包含 6 组电压-电流数据，方便立即体验全部功能。

## 四、数据处理工具箱

实验数据的统计分析、图表绘制与拟合工具，专为实验报告设计。

### 4.1 数据输入

- 支持粘贴 CSV 格式（逗号 / 分号 / 制表符 / 空格分隔）
- 自动识别表头行（非全数字的首行视为表头）
- 也可手动在文本框中逐行输入数值
- 内置示例数据：伏安法测电阻的 6 组 U-I 数据

### 4.2 自动统计

对每个数值列自动计算：

| 指标 | 说明 |
| --- | --- |
| 样本数 n | 有效数据点个数 |
| 均值 x̄ | 算术平均值 |
| 方差 s² | 样本方差（n-1 分母） |
| 标准差 s | 样本标准差 |
| 误差范围 | 95% 置信区间半宽度（±1.96 × 标准误差） |
| 极差 | 最大值 - 最小值 |

### 4.3 图表绘制

- 三种图表类型：**折线图**、**散点图**、**柱状图**
- 自由选择任意两列作为 X 轴和 Y 轴
- 等间距网格线，自动调整坐标范围和刻度

### 4.4 曲线拟合

支持多种拟合方式，自动计算参数和拟合优度：

| 拟合方式 | 模型 | 参数数量 |
| --- | --- | --- |
| 线性拟合 | y = ax + b | 2 |
| 二次多项式 | y = ax² + bx + c | 3 |
| 三次多项式 | y = ax³ + bx² + cx + d | 4 |
| 四次多项式 | y = ax⁴ + ... | 5 |

- 拟合公式显示在图表图例中
- R² 拟合优度显示在结果区域（可一键复制）
- 拟合曲线以虚线叠加在图表上

### 4.5 导出图片

一键将图表导出为 PNG 格式，可直接粘贴到实验报告 Word / PDF 中。

## 五、界面与交互

### 5.1 顶栏工具切换

页面顶部固定导航栏，深色半透明背景 + 毛玻璃效果，包含四个工具标签：

- **科学计算器**（金色高亮激活态）
- **布尔化简**
- **实验记录**
- **数据处理**

当前栏目保存在 localStorage，下次打开自动恢复。也支持 URL 深链接：
- `index.html#boolean` → 直达布尔化简
- `index.html#labrec` → 直达实验记录
- `index.html#dataproc` → 直达数据处理

### 5.2 计算器内模式切换

计算器页面内有 11 个模式标签，采用横向滚动设计，点击切换工作区。

### 5.3 快速查找

顶部搜索框（`Ctrl+K` 聚焦），输入关键字可筛选计算器页面中的所有按钮和模式标签（标签仅淡化不隐藏，保证可切换）。

### 5.4 悬停说明

鼠标悬停在计算器按钮上时，底部显示中文功能说明，帮助用户快速了解每个按键的作用。

### 5.5 数据持久化

所有数据和设置保存在浏览器 localStorage 中，刷新页面或关闭浏览器后数据不丢失：
- 计算器：表达式、角度模式、内存值、计算历史、各模式数据
- 布尔化简：变量配置、真值表数据、计算结果
- 实验记录：所有项目数据和照片
- 数据处理：输入数据、图表设置、拟合设置
- 工具选择记忆：上次使用的栏目

### 5.6 键盘快捷键

| 快捷键 | 功能 |
| --- | --- |
| `0`-`9` `.` `+` `-` `*` `/` `^` `(` `)` | 输入数字和运算符 |
| `Enter` / `=` | 计算表达式 |
| `Backspace` | 删除最后一个字符 |
| `Escape` | 清空搜索框或清空表达式 |
| `Ctrl+K` | 聚焦搜索框 |

### 5.7 移动端适配

- 计算器采用单屏布局，按键区域自适应屏幕宽度
- 实验记录支持手机拍照（`<input capture="environment">`）
- 工具栏目页面支持自由滚动，无高度限制
- 所有触摸操作均针对移动端优化

## 六、技术架构

### 6.1 文件结构

| 文件 | 说明 | 行数（约） |
| --- | --- | --- |
| `index.html` | 页面结构：顶栏 + 四栏目页面 + 计算器布局 | ~230 |
| `app-cn.js` | 全部逻辑：表达式解析器、工具切换、各模式工作区、QM 算法、实验记录、统计分析与拟合、Canvas 图表引擎 | ~4700 |
| `styles-cn.css` | 样式：深色主题、顶栏、栏目页、桌面单屏 + 移动端自适应 | ~1800 |

### 6.2 内置算法

- **表达式解析器**：词法分析 + 递归下降解析，支持三角/反三角/双曲函数、组合排列、随机数
- **Quine-McCluskey 化简**：素蕴含项生成 → 覆盖集选择（精确搜索 + 启发式）→ 异或/同或检测
- **多项式拟合**：正规方程法求解，支持 1~4 次多项式，输出系数与 R²
- **数值微积分**：中心差分（导数）、辛普森复合积分、级数求和
- **Canvas 图表引擎**：纯 Canvas 2D 实现，支持折线/散点/柱状图、网格线、自动刻度、拟合曲线叠加

### 6.3 外部依赖

**零依赖**——所有功能均使用原生 JavaScript、Canvas API 和 CSS 实现，无任何第三方库。

### 6.4 安全策略

页面使用 Content-Security-Policy 限制资源加载，所有脚本、样式、图片均来自本地文件。
