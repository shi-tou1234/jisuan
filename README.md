# 卡西欧 991 计算台

中文科学计算器网页，卡西欧 fx-991 风格的单屏布局，纯前端实现，零依赖、零网络请求。

## 功能

- **标准**：四则运算、括号、乘方、开方、阶乘、百分比、常量 π/e、三角/反三角/双曲函数、对数指数、组合排列、随机数、Ans 与内存（M+/M-/MR/MC）
- **方程**：2~4 元线性方程组、2~4 次多项式求实根、SOLVE（牛顿法）、不等式求根、比例式
- **矩阵**：2×2 / 3×3 / 4×4 矩阵的加减乘、转置、行列式、逆矩阵
- **向量**：三维向量 v1/v2 的加减、点积、叉积、模长、夹角
- **统计**：样本录入，均值、方差、标准差、极值
- **微积分**：一阶/二阶数值导数、辛普森定积分、Σ 求和（上限 ±100000）
- **复数**：四则运算、共轭、模长、辐角
- **进制**：二 / 八 / 十 / 十六进制互转，支持小数与负数
- **逻辑**：AND、OR、XOR、NOT、XNOR，可按二/八/十/十六进制显示
- **表格**：输入 f(x)、g(x) 与范围步长，生成函数值表
- **工具**：分数化简与带分数互转、度分秒（DMS）、极坐标/直角坐标互转、素因数分解（≤10¹²）、ENG 记数、随机数、科学常数、单位换算（长度/质量/时间/速度/压强/能量/温度）

## 使用方式

直接打开 `index.html` 即可使用（也可部署到任意静态托管）。

- 顶部搜索框可按关键字筛选按钮；搜索时模式标签只会淡化，仍可切换
- 键盘可直接输入数字与运算符；`Enter` 计算，`Backspace` 删除，`Esc` 清空（先清搜索框）
- `Ctrl+K` 聚焦搜索框
- 鼠标悬停按钮可查看中文功能说明
- 表达式、各模式数据与设置自动保存在浏览器 localStorage 中
